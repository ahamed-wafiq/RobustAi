# AI-Guard Machine Learning Pipeline & Colab Training Guide

This directory documents the machine learning training pipeline for **AI-Guard: A Robust AI-Generated Text Detection and Analysis System**. It provides guidance on resolving Google Colab runtime errors, loading the authentic **HC3 (Human ChatGPT Comparison Corpus)**, training the baseline model, and deploying the exported model to a FastAPI backend.

---

## 1. Problem Diagnosis & Root Causes

### Error 1: `RuntimeError: Dataset scripts are no longer supported, but found HC3.py`
- **Root Cause:** In Hugging Face `datasets >= 3.0.0`, support for legacy Python dataset loading scripts (`*.py`) was permanently deprecated and removed for security and Hub standardization.
- Calling `load_dataset("Hello-SimpleAI/HC3", "all")` or `load_dataset("Hello-SimpleAI/HC3")` causes `datasets` to discover `HC3.py` in the repository root and immediately fail.
- **Resolution:** The `Hello-SimpleAI/HC3` repository contains the raw JSON Lines data files directly in its root: `all.jsonl` (70.31 MB), `open_qa.jsonl` (2.78 MB), `wiki_csai.jsonl` (2.10 MB), `finance.jsonl` (9.43 MB), `medicine.jsonl` (2.56 MB), and `reddit_eli5.jsonl` (52.88 MB).
- Instead of executing `HC3.py`, we download `all.jsonl` via `hf_hub_download` (or direct HTTPS URL) and load it using the native Hugging Face `json` builder:
  ```python
  from huggingface_hub import hf_hub_download
  from datasets import load_dataset

  local_file = hf_hub_download(repo_id="Hello-SimpleAI/HC3", filename="all.jsonl", repo_type="dataset")
  dataset = load_dataset("json", data_files=local_file, split="train")
  ```
- This approach is **100% reliable**, compatible with modern `datasets` versions, and requires **no Hugging Face authentication token**.

### Error 2: `huggingface-hub < 2.0` Dependency Warnings in Colab
- **Root Cause:** Pre-installed Colab packages (`gradio-client`, `diffusers`, `tokenizers`) pin constraints such as `huggingface-hub < 2.0` (or `< 1.0`). Running an unconstrained `pip install -U` forces `huggingface-hub` to a newer version that breaks these dependencies.
- **Resolution:** Pin compatible versions without upgrading unrelated packages:
  ```bash
  pip install --quiet "datasets>=2.19.0" "huggingface-hub>=0.20.0" scikit-learn joblib pandas numpy matplotlib seaborn
  ```
- If package binary mismatches occur, restart the Colab runtime via **Runtime → Restart session**, then proceed.

## 2. Dataset Preparation & Leakage Prevention

### Raw Schema
Each record in `all.jsonl` contains:
- `question` (str): Question prompt
- `human_answers` (list[str]): Answers written by human experts
- `chatgpt_answers` (list[str]): Answers generated by ChatGPT (early 2023)
- `source` (str): Sub-corpus origin (`reddit_eli5`, `wiki_csai`, `open_qa`, `finance`, `medicine`)

### Data Transformation Pipeline
1. **Unrolling:** Each answer is extracted into an independent sample with its corresponding label:
   - `0`: Human-written
   - `1`: AI-generated (ChatGPT)
2. **Whitespace Normalization:** Standardize irregular spacing, tabs, and newlines. Filter out trivial snippets (< 25 characters).
3. **Deduplication & Conflict Resolution:** Remove identical texts and detect conflicting labels (samples labeled both 0 and 1).
4. **Grouped Zero-Leakage Splitting (`GroupShuffleSplit`):**
   - **Why naive random splitting fails:** If answers to question $Q_{42}$ appear in both Train and Test, the classifier memorizes question-specific keywords (e.g., historical dates, scientific terminology) rather than true stylistic signatures of synthetic text.
   - **Solution:** Group by `question_id`. All answers to a given question are placed strictly inside Train (70%), Validation (15%), or Test (15%). No question spans across multiple splits.

## 3. Baseline Model Architecture

The baseline pipeline is implemented using `scikit-learn`:

```python
from sklearn.pipeline import Pipeline
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression

pipeline = Pipeline([
    ("tfidf", TfidfVectorizer(
        ngram_range=(1, 2),
        max_features=50000,
        sublinear_tf=True,
        min_df=3,
        strip_accents="unicode"
    )),
    ("clf", LogisticRegression(
        C=2.5,
        max_iter=1000,
        class_weight="balanced",
        solver="lbfgs",
        random_state=42
    ))
])
```

- **Feature Extraction:** Sublinear TF-IDF scaling (`1 + log(tf)`) dampens extreme term frequencies; unigram + bigram capture handles local stylistic collocations (e.g., "in conclusion", "furthermore", "it is important").
- **Classification:** L2-regularized logistic regression with balanced class weights ensures calibrated probability outputs (`predict_proba()`).
- **Validation Tuning:** Hyperparameters (`ngram_range`, `max_features`, `C`) are selected exclusively on the **Validation set**. The **Test set** is evaluated once on the final model.

## 6. FastAPI Backend Integration

### 1. Place Model Artifact
Move `ai_guard_baseline.joblib` to your FastAPI backend directory:
```
backend/
├── app/
│   ├── __init__.py
│   ├── main.py
│   └── models/
│       └── ai_guard_baseline.joblib
└── requirements.txt
```

### 2. FastAPI Endpoint (`main.py`)
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field
from contextlib import asynccontextmanager
import joblib
import os

MODEL_PATH = os.getenv("MODEL_PATH", "models/ai_guard_baseline.joblib")
models = {}

@asynccontextmanager
async def lifespan(app: FastAPI):
    if not os.path.exists(MODEL_PATH):
        raise RuntimeError(f"Model file not found at: {MODEL_PATH}")
    models["baseline"] = joblib.load(MODEL_PATH)
    yield
    models.clear()

app = FastAPI(
    title="AI-Guard Inference API",
    version="1.0.0",
    description="Inference service for AI-generated text detection",
    lifespan=lifespan
)

class DetectionRequest(BaseModel):
    text: str = Field(..., min_length=25, description="Input text to analyze (min 25 characters)")

class DetectionResponse(BaseModel):
    prediction: str
    label: int
    ai_probability: float
    human_probability: float
    confidence_score: float
    word_count: int
    disclaimer: str

@app.post("/api/detect", response_model=DetectionResponse)
async def detect_text(req: DetectionRequest):
    text = req.text.strip()
    words = text.split()
    if len(words) < 5:
        raise HTTPException(status_code=400, detail="Text must contain at least 5 words.")
    
    model = models.get("baseline")
    if model is None:
        raise HTTPException(status_code=503, detail="Model pipeline is not loaded.")
    
    pred_label = int(model.predict([text])[0])
    probs = model.predict_proba([text])[0]
    prob_human = float(probs[0])
    prob_ai = float(probs[1])
    
    # Confidence represents distance from ambiguous decision boundary (0.50)
    confidence = round(abs(prob_ai - 0.50) * 2.0, 4)
    
    return DetectionResponse(
        prediction="AI-Generated" if pred_label == 1 else "Human-Written",
        label=pred_label,
        ai_probability=round(prob_ai, 4),
        human_probability=round(prob_human, 4),
        confidence_score=confidence,
        word_count=len(words),
        disclaimer="Probabilistic estimate for academic research only. Does not prove authorship."
    )
```

## 7. Research Limitations, Bias & Academic Integrity

> [!WARNING]
> **Essential Methodological Disclaimers:**
> 1. **Probabilistic Nature:** Statistical text detectors yield likelihood estimates based on vocabulary frequency distributions. They cannot provide forensic proof of human or synthetic origin.
> 2. **Non-Native English (ESL) Bias:** Writers using English as a second language frequently produce essays with lower lexical diversity and more formulaic syntactic structures. Baseline classifiers can misclassify these samples as AI-generated, producing harmful false positives.
> 3. **Evasion Susceptibility:** Light paraphrasing, synonym substitution, prompt rephrasing, or character noise will rapidly degrade TF-IDF features.
> 4. **Temporal & Domain Shift:** The HC3 corpus was collected using early ChatGPT (late 2022 / early 2023). Newer frontier models (GPT-4o, Claude 3.5, Gemini 1.5) exhibit distinct discourse characteristics.
